Cấu Hình Đường Dẫn API (MockAPI Endpoint)

Hệ thống hỗ trợ kết nối trực tiếp với mockapi.io của bạn hoặc chuyển đổi chế độ Mock Data nội bộ bất kỳ lúc nào.

Ví dụ mẫu: https://6750000000000000.mockapi.io/drinks

📋 Hướng dẫn tạo Resource trên MockAPI.io theo đề bài:

  1. Truy cập mockapi.io và đăng nhập bằng tài khoản cá nhân.
  2. Nhấn nút "New Project" → Đặt tên là CafeManagement → Nhấn Create.
  3. Nhấn "New Resource" → Đặt tên Resource là drinks.
  4. Tại phần Schema, khai báo các trường:
    • id: Object ID (hệ thống tự tạo)
    • createdAt: Faker.date (hệ thống tự tạo)
    • name: Kiểu String (Tên món đồ uống)
    • price: Kiểu Number (Giá bán tính bằng VNĐ)
    • category: Kiểu String (Danh mục đồ uống)
    • image: Kiểu String (Đường dẫn ảnh món)
    • status: Kiểu Boolean (Đang bán / Tạm hết)
  5. Nhấn Create → Sao chép đường link endpoint dạng https://...mockapi.io/drinks và dán vào ô trên.
  6. Tạo thêm Resource orders với các trường: table, drinkId, drinkName, note, status (String) và unitPrice, quantity, total (Number) để đồng bộ đơn hàng.
